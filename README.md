# Devex — プロジェクトスコープ定義

Devexは、AI(LangChain等)を活用した対話型インターフェースを通じてユーザーのアイデアや要望を引き出し、高品質な「要件定義」「外部設計」「内部設計」「実装計画」のMarkdownドキュメントを自動生成・出力するシステムである。システム開発の初期フェーズにおけるドキュメント作成の工数・属人化を解消することを目指す。

詳細仕様は以下の4ドキュメントに分割している(Devex自身が生成する4種のドキュメントと同じ構成 ── [外部設計書](docs/external_design.md) 2.3節 SCR-005参照)。

| ドキュメント | 内容 |
| :--- | :--- |
| [要件定義書](docs/requirements.md) | 目的・背景、ターゲットユーザー、In Scope/Out of Scope、機能要件(MoSCoW)、非機能要件、制約条件 |
| [外部設計書](docs/external_design.md) | システム構成、画面一覧・遷移、UI/UX仕様、外部API連携、データ入出力仕様 |
| [内部設計書](docs/internal_design.md) | 技術スタック・アーキテクチャ方針、データモデル、バックエンド処理・モジュール設計、エラーハンドリング |
| [実装計画書](docs/implementation_plan.md) | 開発ステージ分割・マイルストーン、WBS、開発環境・CI/CD、想定リスクと対策 |

CL(Curriculum Loop)開発の進行ルール・プロジェクトゴールは [`CLAUDE.md`](CLAUDE.md) を参照。
