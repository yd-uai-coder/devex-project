# Phase 39 導入: 効果測定(ステージ6)

## 目的

ステージ6(Phase 34〜38: 観点の表・選択肢カード・要件定義書と外部設計書のモデル化・要件の追跡)が、ヒアリングの聞き漏れと要件の推測を本当に減らしたかを、[ベースライン](../../appendix/measurements/stage6-baseline.md)([Phase 33-1](../Phase-33/Phase-33-1.md))と同じペルソナ・規則で、実際の LLM で流して数字で確かめる。基準に届かなければ、原因を直して再測定する。[README](../../README.md) のステージ表と[実装計画書](../../docs/implementation_plan.md)のマイルストーン7「ベースラインと比べて、聞けた事実が増え、要件の『推測』が減ったことを数字で示せる」を、この Phase で満たす。

計画は [33-5](../Phase-33/Phase-33-5.md) の Phase 39。測定の生成物は [`appendix/measurements/stage6-effect.md`](../../appendix/measurements/stage6-effect.md)。

## モード宣言(#21)・E2E の宣言(#36)

自動実装モード: **on**(測定で見つけた原因を、AI が本体へ直し、`textbook/samples/` も同じ内容で作る)。

E2E: この Phase では流さない。判定の取り込みの規則が変わり(採用と規模・技術スタックは利用者の発言からだけ)、最初の発話には必ず規模のカードが出る。偽 LLM の判定は利用者の最後の発言を根拠にするので、E2E の流れ(発話3回で十分)は変わらない見込み。Phase 40 で既存を含めて全部流して確かめる。

## 着手時の相談で決めたこと

詳細は [`q_a.md`](../q_a.md) の「Phase 39 開始時」と「Phase 39 ── 1回目の測定の後の直し」を参照。

1. **自動実装モード**: on。
2. **成功の基準**(33-5 の未確定事項): **厳しめ**(ユーザーの選択。推奨は「3指標すべて改善」)── ① 分類 A が両モード 0件 ② 聞けた潜在の事実が両モード 10/14 以上 ③ 技術スタックの創作 0、かつ利用者が言っていない要件はすべて「推測」。未達なら直して再測定。

実装中の判断(選んだ直しの範囲を広げたもの。[39-2](./Phase-39-2.md)・[39-3](./Phase-39-3.md)):

- **技術スタックもチャットで確かめる観点に**: 判定が条件を無視して技術スタックを初期入力から「決定」にしたため、規模と同じくコードの規則で守った(`confirm_in_chat`)。

- **技術スタックの要約に名前をすべて残す**: 要件定義書の生成が要約を読み、LLM を落としたため。

この Phase で生まれたもの:

- **聞かれない潜在の事実**: L2(バックアップ)・L5(ログに本文を残さない)・L6(不正利用)・L14(削除)は、どの回も聞かれなかった。観点1つに問いが1つで、可用性(データの保全)・セキュリティ(ログ・不正利用)の2つ目の側面に届かない。観点の条件に足すか、追いの問いを足すかを決める。
- **判定のゆらぎ**: 直前の問いを添えても、自由回答を「採用」にすることが残る(出どころが「採用」になるだけ)。LLM の一時的な出力の乱れ(文字化け)も1回あった。
- **規模の CON の出どころ**: 利用者がカードで選んだ規模が、要件定義書では「推測」になる(どの回も1行)。規模の観点を出どころの上限の計算に入れるかを決める。
- **`API_BODY_MISSING` の誤検知**: 本文の要らない POST(`/generate`)にも中程度の警告が出る。本文の欄に「なし」を書かせるか、検証を緩めるかを決める。
- **手順書の index の見出しの二重**: 簡易モードの index の「2. 実装前提・制約」で、実装計画書の見出しが「### ### 1.」と二重になる(1回目の簡易)。
- **`_ensure_question` の問いの二重**: 返信が「〜について教えてください。」(「？」なし)で終わると、コードが同じ観点の問いを足して二重になる(2回目の簡易の1発言目)。
- **技術スタックは開発環境のフォームを埋めてもチャットで確かめる**: 39-2 の規則の結果。フォームの値がカードのおすすめに出るかを Phase 40 の画面確認で見る。
- **任意の観点のヒアリングの質**: 規則で任意を続けなかったので測っていない。Phase 40 の画面確認で見る。
- **セッションの区切りの記録**: Phase 39 は1セッションで行った(計画モードで質問4問 → 1回目の測定 → 直しの選択4つ → 直し → 2回目の測定と追加の直し → samples → 教材 → 全体テスト)。
