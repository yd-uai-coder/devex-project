## 後の Phase への前提

- **Phase 117(効果測定・統合/E2E・10.8節)**: 取り込みの E2E の spec(資料の追加 → 違いの取り出し → 違いを選んで CR の下書き → CR の詳細)は、この Phase の画面の名前で書ける(「資料を足す」「最新の版 B-n と比べて違いを取り出す」「「<内容>」を選ぶ」「選んだ違いから CR の下書きを作る」)。E2E の dev サーバーは偽の LLM なので、違いは偽の LLM の印(`[違い:<kind>:<key>]`。Phase 114)で本文に書く。既存の E2E も含めて全部流す(#36)。束の一覧に鮮度の列を足したので、束の表の列を数える E2E があれば合わせる。
- **ユーザーの画面確認**(Phase 117 の開発環境での確認): 資料の画面一式と、束が古いときの知らせ(資料・CR の詳細・共有リンク・束の中身)と規模の表の「(古い)」。「予約の CR」に、この Phase の画面確認で作った資料と CR-4 がある。
