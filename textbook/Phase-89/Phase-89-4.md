## 準備

- devex-api は通常の `docker compose up`(実 LLM。`E2E_FAKE_LLM` を付けない)、devex-ui は `npm run dev`(3000 番)。89-2 の E2E の後、この形に戻した。
- 確認に使う利用者のマイページで、用途「生成」のモデルが **Gemini 3.5 Flash-Lite** であることを先に確かめる(Claude を選んでいると費用の見積もりが変わる)。
- 詳細設計モードのプロジェクトを1つ使う。文書(要件定義書・外部設計書)まであれば既存のものでよい。段階を承認したプロジェクトなら、段階への反映と印も見られる。
