## 後の Phase への前提

- **Phase 116(画面)**: 資料の画面で、違いの一覧にチェックボックス(未確認の追加・変更・削除だけ)と、画面・API・外部連携の違いの候補の要件の選択(既定は全部)を置き、`POST .../materials/{mid}/change-requests` で作ったら CR の詳細へ移る。CR にした違いは CR の番号(リンク)を出す。`MATERIAL_DIFFERENCE_OUTDATED` のときは取り出し直しへ案内する。CR の詳細・説明書・共有リンクの作成の応答の `baseline_freshness` が古ければ知らせ(後の束・束の後の CR と要素・古かった段階)と、束を作り直す画面への案内を出す。規模の表は `state` で「古い」と「数えられない」を分けて見せる。
- **Phase 117(効果測定・E2E・10.8節)**: マイルストーン15 の (5)「選んだ違いから作った CR の下書きが、対象・背景を持ち、そのまま説明済みにできる」は、この Phase の API で測る。マイグレーション `d5a1c7e3f926` の往復と、`OPERATIONS.md` 10.8節のステージ14 の分(説明書の md が1行変わるので、本番の説明済みの CR の確認済みの要約は確かめ直しになる)。取り込みの E2E の spec(資料の追加 → 違いの一覧 → CR の下書き)。
