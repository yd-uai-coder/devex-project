# 2. 外部設計書

## 2.1 システム構成概要

本システムは、Next.js(App Router) + Tamaguiによるフロントエンドと、FastAPI + LangChain・LangGraph(Python 3.13)によるバックエンドで構成されるWebアプリケーションです。データベースにはPostgreSQL、レート制限やトークン管理にはRedisを使用します。インフラストラクチャはVPS上にDocker Composeとnginxを配置し、GitHub Actionsにより自動デプロイを行います。外部AIサービスとしてGemini Flash-Liteを利用します。

## 2.2 画面一覧・画面遷移フロー（概要）

| 画面ID | 画面名 | 主要な役割 | 優先度 | 要件 |
|---|---|---|---|---|
| SCR-001 | ログイン・ユーザー登録画面 | メールアドレスとパスワードによる認証および新規登録を行う。 | Must | FR-001 |
| SCR-002 | チャットヒアリング・初期資料読込画面 | 参考資料のアップロードと、AIとの対話による要件ヒアリングを行う。 | Must | FR-002・FR-006・FR-009 |
| SCR-003 | 設計書プレビュー・診断画面 | 4種のMarkdown設計書のプレビュー確認、AIによる不足点の3段階診断結果の確認、コピー・ダウンロードを行う。 | Must | FR-003・FR-004・FR-005 |

```text
SCR-001 (ログイン) -> SCR-002 (チャットヒアリング・資料読込) -> SCR-003 (設計書プレビュー・診断)
```

## 2.3 主要画面のUI/UX仕様

### SCR-001: ログイン・ユーザー登録画面

- 入力項目: メールアドレス、パスワード
- 操作ボタン: ログインボタン、新規登録ボタン
- アクション: 入力情報を基に認証APIを呼び出し、JWTを取得してメイン画面へ遷移する

### SCR-002: チャットヒアリング・初期資料読込画面

- 入力項目: チャットメッセージ入力欄(数千文字制限、空送信禁止)、参考資料ファイルアップロード(txt/md/pdf、最大3件)
- 表示項目: チャット履歴、AIの応答メッセージ
- 操作ボタン: メッセージ送信ボタン、資料添付ボタン、設計書生成トリガーボタン
- アクション: メッセージを送信しAIの応答を表示する。資料をアップロードする。十分なヒアリング後に設計書生成処理へ移行する

### SCR-003: 設計書プレビュー・診断画面

- 表示項目: 4種のMarkdown設計書プレビュー、AIの不足点自己診断結果(最重要/中程度/軽微の3段階)
- 操作ボタン: コピーボタン、ダウンロードボタン、再生成ボタン
- アクション: 設計書の内容をクリップボードにコピーする。設計書ファイルをダウンロードする。再生成を指示する

## 2.4 外部システム・API連携仕様

| サービス | 用途 | 認証 | タイミング | 要件 |
|---|---|---|---|---|
| Gemini Flash-Lite API | チャットヒアリングの対話応答、4種のMarkdown設計書の生成、不足点の3段階自己診断 | API Key | リアルタイム対話時および設計書生成・診断時 | FR-002・FR-003・FR-004・CON-004 |

## 2.5 データ入出力仕様

- 受付フォーマット: 参考資料として txt, md, pdf 形式のファイル（最大3件）を受け付ける。
- 出力フォーマット: 4種のMarkdown設計書（要件定義、外部設計、内部設計、実装計画）のテキストおよびダウンロードファイル。
- バリデーション: チャット入力は数千文字までの制限を満たしていること、空文字でないことを検証する。ファイルアップロードは指定拡張子と最大件数（3件）を検証する。

## 2.6 API一覧

| メソッド | パス | 概要 | 関連画面 | 要件 | 本文 | 応答 | エラー |
|---|---|---|---|---|---|---|---|
| POST | /api/v1/auth/register | ユーザー登録 | SCR-001 | FR-001 | email, password | 201 ユーザー作成完了 | 400 不正な入力、409 メールアドレス重複 |
| POST | /api/v1/auth/login | ログイン | SCR-001 | FR-001・NFR-008 | email, password | 200 ログイン成功(HttpOnly CookieにJWT設定) | 401 認証失敗 |
| POST | /api/v1/chat/messages | チャットメッセージ送信とAI応答取得 | SCR-002 | FR-002・FR-008・FR-009 | message | 200 AI応答データ | 400 入力文字数オーバーまたは空文字、500 AI応答失敗 |
| POST | /api/v1/documents/generate | 4種設計書の一括生成と自己診断の実行 | SCR-002 / SCR-003 | FR-003・FR-004・FR-007・FR-008 | none | 201 生成された4種設計書および診断結果 | 500 生成失敗時の再生成エラー |
| POST | /api/v1/documents/upload-reference | 参考資料のアップロード | SCR-002 | FR-006 | file | 201 アップロード完了 | 400 サポート外の形式または最大件数超過 |
