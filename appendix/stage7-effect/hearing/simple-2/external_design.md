# 2. 外部設計書

## 2.1 システム構成概要

```
[ユーザー (Chrome/Edge/Firefox/Safari)]
        │ (HTTPS)
        ▼
[nginx / Docker Compose (VPS)]
        │
        ├─► [Next.js (App Router) / Frontend]
        │         │ (REST API / JWT)
        │         ▼
        └─► [FastAPI / LangChain・LangGraph (Python 3.13) / Backend]
                  │
                  ├─► [PostgreSQL (永続データ)]
                  ├─► [Redis (レート制限・トークン失効)]
                  └─► [Gemini Flash-Lite (LLM)]
```

## 2.2 画面一覧・画面遷移フロー（概要）

| 画面ID | 画面名 | 主要な役割 | 優先度 | 要件 |
|---|---|---|---|---|
| SCR-001 | ユーザー登録・ログイン画面 | 新規ユーザーの登録および既存ユーザーのログインを行う | Must | FR-001・FR-002 |
| SCR-002 | メイン機能画面（初期入力・チャットヒアリング・設計書生成） | 参考資料の読み込み、チャット形式のヒアリング、4種設計書の一括生成と自己診断の提示を行う | Must | FR-003・FR-004・FR-005・FR-007・FR-008 |
| SCR-003 | 設計書プレビュー・出力画面 | 生成された Markdown 設計書のプレビュー表示、コピー、ダウンロードを行う | Must | FR-006 |

```text
SCR-001 (登録・ログイン) -> SCR-002 (メイン機能画面: ヒアリング・生成・自己診断) <-> SCR-003 (設計書プレビュー・出力)
```

## 2.3 主要画面のUI/UX仕様

### SCR-001: ユーザー登録・ログイン画面

- 入力項目: メールアドレス、パスワード
- 操作ボタン: 登録ボタン、ログインボタン
- アクション: 入力検証後、認証APIを呼び出してトークンを取得しメイン画面へ遷移する

### SCR-002: メイン機能画面（初期入力・チャットヒアリング・設計書生成）

- 入力項目: 参考資料ファイルアップロード(txt, md, pdf、最大3件)、チャットメッセージ入力欄(数千文字まで、空送信禁止)
- 表示項目: チャット履歴、生成された4種設計書(要件定義・外部設計・内部設計・実装計画)、AIによる各文書の不足点自己診断結果(3段階: 最重要/中程度/軽微)
- 操作ボタン: ファイル選択・アップロードボタン、メッセージ送信ボタン、再送ボタン、再生成ボタン
- アクション: メッセージ送信によりAIヒアリングを実行、完了時に設計書を一括生成・自己診断を表示、エラー時は再送・再生成を促す

### SCR-003: 設計書プレビュー・出力画面

- 表示項目: 選択した設計書の Markdown プレビュー画面
- 操作ボタン: クリップボードへコピーボタン、ファイルダウンロードボタン
- アクション: プレビュー内容をクリップボードにコピーまたはローカルファイルとしてダウンロードする

## 2.4 外部システム・API連携仕様

| サービス | 用途 | 認証 | タイミング | 要件 |
|---|---|---|---|---|
| Gemini Flash-Lite API | チャットヒアリング、4種設計書の自動生成、自己診断の実行 | APIキー認証 | ユーザーからのチャット送信時および設計書生成リクエスト時 | FR-004・FR-005・CON-004 |

## 2.5 データ入出力仕様

- 受付フォーマット: 参考資料として txt, md, pdf (最大3件)、チャット入力は数千文字までのテキスト。
- バリデーション: 空メッセージの送信禁止、ファイル形式および最大3件の件数制限チェック、レート制限(Redisによる不正利用防止)。

## 2.6 API一覧

| メソッド | パス | 概要 | 関連画面 | 要件 | 本文 | 応答 | エラー |
|---|---|---|---|---|---|---|---|
| POST | /api/v1/auth/register | ユーザー登録 | SCR-001 | FR-001・FR-008 | email, password | 201 ユーザー登録成功 | 400 入力値不正、409 重複メールアドレス、429 レート制限超過 |
| POST | /api/v1/auth/login | JWT認証ログイン | SCR-001 | FR-002・FR-008 | email, password | 200 ログイン成功(HttpOnly Cookieにアクセストークン・リフレッシュトークン設定) | 401 認証失敗、429 レート制限超過 |
| POST | /api/v1/projects | プロジェクト作成・参考資料アップロード | SCR-002 | FR-003・NFR-006 | files (txt/md/pdf, 最大3件) | 201 プロジェクト作成成功 | 400 ファイル形式不正または件数超過、401 認証エラー |
| POST | /api/v1/chat/messages | チャットメッセージ送信とAIヒアリング応答 | SCR-002 | FR-007・FR-008・NFR-003 | message | 200 AI応答成功 | 400 空メッセージまたは文字数超過、500 AI応答失敗(メッセージ未保存) |
| POST | /api/v1/documents/generate | 4種設計書の一括生成と自己診断の実行 | SCR-002 / SCR-003 | FR-004・FR-005・FR-007・NFR-003 | project_id | 201 設計書生成・自己診断成功 | 500 生成失敗(再生成可能) |
