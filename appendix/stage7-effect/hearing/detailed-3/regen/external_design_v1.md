# 2. 外部設計書

## 2.1 システム構成概要

```
[ブラウザ(Next.js + Tamagui)]
       │ (HTTPS)
       ▼
[nginx (VPS)]
       │
[FastAPI + LangChain/LangGraph (Python 3.13)]
       ├── PostgreSQL (データ保存)
       ├── Redis (レート制限・トークン失効管理)
       └── Gemini Flash-Lite (外部LLM API)
```

## 2.3 主要画面のUI/UX仕様

### SCR-001: ログイン・ユーザー登録画面

- 入力項目: メールアドレス、パスワード
- 操作ボタン: ログインボタン、ユーザー登録ボタン
- アクション: 入力情報を基に認証APIを呼び出し、成功時はプロジェクト一覧画面へ遷移する

### SCR-002: プロジェクト一覧・作成画面

- 表示項目: 既存プロジェクト一覧
- 入力項目: 新規プロジェクト名
- 操作ボタン: プロジェクト作成ボタン、プロジェクト選択ボタン
- アクション: 選択したプロジェクトのチャットヒアリング画面へ遷移する

### SCR-003: チャットヒアリング画面

- 表示項目: チャット履歴、AIの応答メッセージ
- 入力項目: チャットメッセージ入力欄（数千文字まで・空送信不可）、参考資料ファイル選択（txt, md, PDF）
- 操作ボタン: メッセージ送信ボタン、ファイルアップロードボタン、ヒアリング完了ボタン
- アクション: メッセージ送信時はAI応答またはエラー・再送案内を表示。完了時は構造化サマリ確認画面へ遷移する

### SCR-004: 構造化サマリ確認画面

- 表示項目: 構造化されたサマリ内容
- 操作ボタン: 承認して文書生成へ進むボタン、修正依頼ボタン
- アクション: 承認時に文書生成プロセスを開始し文書プレビュー画面へ遷移する

### SCR-005: 文書プレビュー・自己診断画面

- 表示項目: 4種文書（要件定義、外部設計、内部設計、実装計画）のMarkdownプレビュー、AIによる不足点の自己診断結果、版の履歴（直近3件）
- 操作ボタン: コピーボタン、ダウンロードボタン、再生成ボタン、版切り替えボタン
- アクション: 各種操作に応じた機能を実行する

## 2.4 外部システム・API連携仕様

| サービス | 用途 | 認証 | タイミング | 要件 |
|---|---|---|---|---|
| Gemini Flash-Lite | チャットヒアリングの応答生成、構造化サマリ作成、4種文書の順次生成および自己診断 | APIキー | ユーザーからのメッセージ送信時および文書生成時 | CON-004・FR-002・FR-005・FR-006 |

## 2.5 データ入出力仕様

- 受付フォーマット: 参考資料として txt, md, PDF ファイルを受け付ける。
- バリデーション: チャットメッセージは数千文字以内かつ空送信不可。ファイル形式は指定の拡張子のみ許可する。
