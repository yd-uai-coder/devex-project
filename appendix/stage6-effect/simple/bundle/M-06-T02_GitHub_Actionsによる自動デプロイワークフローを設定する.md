# M-06-T02 GitHub Actionsによる自動デプロイワークフローを設定する

> 種別: 基盤 / マイルストーン: M-06 Docker・Nginx・CI/CDによるデプロイ基盤構築 / 要件: CON-006 / 依存: M-06-T01

## 目的

GitHub Actionsによる自動デプロイワークフローを設定し、mainブランチへのプッシュ時にVPS上のDocker Compose環境へ自動でデプロイできるようにする。

## 対象の処理・参照する設計

- 内部設計書 3.2 データモデル

## 作成・変更するファイル(依存順)

| ファイル | 種類 | 責務 | 根拠 |
|---|---|---|---|
| `.github/workflows/deploy.yml` | 環境・設定 | mainブランチへのプッシュをトリガーとした自動デプロイのワークフローを定義する | 段階7 環境・設定のファイル |

## 実装の要点(設計に書いていないことだけ)

- VPSへの接続に必要なSSH秘密鍵やホスト名などの機密情報は、GitHub Actionsのシークレットに設定することを前提とする。

## テスト観点

| # | 観点 | SUT | ドライバ | スタブ |
|---|---|---|---|---|
| TC-01 | GitHub Actionsのワークフロー定義ファイルの構文が正しく、YAMLとしてパースできること | .github/workflows/deploy.yml | 静的構文チェック（YAMLlint等）またはGitHub上のワークフロー構文チェッカー | スタブ不要 ── 設定ファイルのため |

- Given 変更した .github/workflows/deploy.yml ファイルが存在する
- When GitHubリポジトリのmainブランチにコードがプッシュされる
- Then GitHub Actionsにより自動デプロイワークフローが実行される

## 確認方法

- GitHubのリポジトリ画面でActionsタブを開き、ワークフローファイルが正常に読み込まれていることを確認する。
- mainブランチへテストプッシュを行い、デプロイアクションが意図通りにトリガーされることを確認する。
