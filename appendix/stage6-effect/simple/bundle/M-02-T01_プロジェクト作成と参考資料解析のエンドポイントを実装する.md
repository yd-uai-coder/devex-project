# M-02-T01 プロジェクト作成と参考資料解析のエンドポイントを実装する

> 種別: 機能 / マイルストーン: M-02 プロジェクト作成と参考資料読み込み機能 / 要件: FR-005, FR-006 / 依存: M-01-T02

## 目的

プロジェクト作成と参考資料解析のAPIエンドポイントを追加し、利用者からの入力を受け付けてprojectsテーブルに保存できるようにする。

## 対象の処理・参照する設計

- 内部設計書 DF-001 POST /api/v1/projects
- 内部設計書 3.3 `backend/app/api/v1/endpoints/projects.py`

| ファイル | 種類 | 責務 | 根拠 |

| `backend/app/api/v1/router.py` | モジュール | プロジェクト作成のエンドポイントをルーターに登録する。 | backend/app/api/v1/router.py |
| `backend/app/api/v1/endpoints/projects.py` | モジュール | POST /api/v1/projects のリクエスト受付、バリデーション、レスポンス返却を行う。 | backend/app/api/v1/endpoints/projects.py |

- データベースのprojectsテーブルにレコードが正しく保存されていることを確認する
