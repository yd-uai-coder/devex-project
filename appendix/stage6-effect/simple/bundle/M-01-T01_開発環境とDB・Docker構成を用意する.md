# M-01-T01 開発環境とDB・Docker構成を用意する

> 種別: 基盤 / マイルストーン: M-01 プロジェクト基盤とデータベース構築 / 要件: — / 依存: なし

## 目的

開発環境およびデータベースのコンテナ構成を構築し、バックエンドの基本設定と起動確認を行う。

## 対象の処理・参照する設計

- 内部設計書 3.2 データモデル

## 作成・変更するファイル(依存順)

| ファイル | 種類 | 責務 | 根拠 |
|---|---|---|---|
| `docker-compose.yml` | 環境・設定 | Docker Composeによるマルチコンテナ環境の定義を行う | 段階7 環境・設定のファイル |
| `backend/Dockerfile` | 環境・設定 | FastAPIバックエンド用のコンテナイメージ構築手順を定義する | 段階7 環境・設定のファイル |
| `backend/requirements.txt` | 環境・設定 | Python依存パッケージのバージョン固定と管理を行う | 段階7 環境・設定のファイル |
| `backend/app/core/config.py` | モジュール | 環境変数やアプリケーション設定の読み込みと管理を行う | 段階4 |
| `backend/app/core/database.py` | モジュール | PostgreSQLデータベースへの接続セッション管理を行う | 段階4 |
| `backend/app/main.py` | モジュール | FastAPIアプリケーションのエントリポイントとルーティング初期化を行う | 段階4 |

## 実装の要点(設計に書いていないことだけ)

- 基盤構築の単位であるため、docker-compose.ymlなどの設定ファイルから順に作成し、最後にバックエンドのエントリポイントを実装する。

## テスト観点

| # | 観点 | SUT | ドライバ | スタブ |
|---|---|---|---|---|
| TC-01 | アプリケーションが正常に起動し、ヘルスチェックやルートパスへのアクセスに応答することを確認する | backend/app/main.py | curlによるAPIの疎通確認 | スタブ不要 ── 外部依存無しの初期起動確認のため |

- Given 開発環境のDocker Composeコンテナが起動している
- When ルートパスへHTTPリクエストを送信する
- Then 正常なレスポンスが返却される

## 確認方法

- docker compose up --build によりすべてのコンテナがエラーなく起動することを確認する
- curlまたはブラウザでバックエンドの起動確認エンドポイントにアクセスし、応答があることを確認する
