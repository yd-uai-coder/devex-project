## 規則の差分(ペルソナはそのまま)

- 規則5の発言の上限を、8回から **20回** にした(問いが1回に1つになったため。カードへの回答も1発言)。
- カードは、事実に合う選択肢を選ぶ。どれも一部しか合わないときは自由回答で答える(ペルソナの事実を正確に伝えるため)。
- 規模のカードは「誰でも登録できるサービス」を選んだ(想定ユーザーが SE・コンサル・個人開発者・創業者と不特定のため)。
- 観点の表の「対象外(後で決める)」は使わない。必須がそろったら任意の観点は続けない。
- 同じ問い(カードの付け直し)が来たら、もう一度同じ内容で答える。
