# 2. 外部設計書

## 2.1 システム構成概要

本システムは、Next.jsによるフロントエンドとFastAPIによるバックエンドで構成され、VPS上のDocker環境へデプロイされる。ユーザーはJWT認証を通じてログインし、PostgreSQLにプロジェクト、チャット履歴、生成文書を安全に保存する。外部AIサービスと連携して対話型ヒアリングや設計書一括生成処理を実行する。

```
[ユーザー / ブラウザ] 
       │ (HTTPS / JWT認証)
       ▼
[Next.js (フロントエンド)]
       │ (REST API)
       ▼
[FastAPI (バックエンド)] ── (データ永続化) ──> [PostgreSQL]
       │
       └─ (API連携) ──> [外部AIサービス]
```

## 2.2 画面一覧・画面遷移フロー（概要）

| 画面ID | 画面名 | 主要な役割 | 優先度 | 要件 |
|---|---|---|---|---|
| SCR-001 | ログイン画面 | メールとパスワードを用いてユーザー認証を行う。 | Must | FR-006 |
| SCR-002 | ダッシュボード・初期入力画面 | プロジェクトの新規作成および参考資料の読み込みを行う。 | Must | FR-005・NFR-007 |
| SCR-003 | チャットヒアリング画面 | 対話形式のヒアリングを実施し、要件を深掘りする。 | Must | FR-001・FR-007・FR-008・NFR-003 |
| SCR-004 | 設計書一括生成・プレビュー画面 | 4種の設計書の生成、プレビュー、自己診断結果の確認を行う。 | Must | FR-002・FR-003・FR-004・NFR-004 |
| SCR-005 | テンプレート選択画面 | 設計書生成時のテンプレートを選択する。 | Should | FR-009 |
| SCR-006 | 版の履歴画面 | 過去に生成した設計書の版履歴を確認する。 | Should | FR-010 |
| SCR-007 | 設計図(UML)表示画面 | 生成された設計図(UML)を確認・編集する。 | Should | FR-011 |

```text
SCR-001 (ログイン) -> SCR-002 (ダッシュボード) -> SCR-003 (チャットヒアリング) -> SCR-004 (設計書プレビュー)
SCR-002 <-> SCR-005 (テンプレート選択: Should)
SCR-004 -> SCR-006 (版の履歴: Should)
SCR-004 -> SCR-007 (設計図UML: Should)
```

## 2.3 主要画面のUI/UX仕様

### SCR-001: ログイン画面

- 入力項目: メールアドレス、パスワード
- 操作ボタン: ログインボタン
- アクション: 入力情報を基に認証APIを呼び出し、JWTトークンを保存してダッシュボードへ遷移する。

### SCR-002: ダッシュボード・初期入力画面

- 入力項目: プロジェクト名、参考資料ファイル選択(txt/md/pdf、最大3件)
- 表示項目: 過去のプロジェクト一覧
- 操作ボタン: 新規プロジェクト作成ボタン、資料アップロードエリア
- アクション: 資料をアップロードしてチャットヒアリング画面へ遷移する。

### SCR-003: チャットヒアリング画面

- 入力項目: チャットメッセージ入力欄(数千文字まで、空送信禁止)
- 表示項目: チャット履歴一覧、AI応答中インジケーター、エラー理由表示
- 操作ボタン: 送信ボタン、設計書一括生成ボタン
- アクション: メッセージ送信によりAPIを呼び出し、AIの応答を表示する。失敗時は理由を表示して再送を促す。

### SCR-004: 設計書一括生成・プレビュー画面

- 表示項目: 4種の設計書タブ(要件定義・外部設計・内部設計・実装計画)、Markdownプレビュー領域、自己診断結果(3段階: 最重要/中程度/軽微)
- 操作ボタン: コピーボタン、ダウンロードボタン、設計書再生成ボタン
- アクション: 生成されたMarkdown文書のコピーおよびファイルダウンロードを行う。

### SCR-005: テンプレート選択画面

- 表示項目: テンプレート一覧と詳細
- 操作ボタン: テンプレート適用ボタン

### SCR-006: 版の履歴画面

- 表示項目: バージョン一覧、変更差分表示
- 操作ボタン: 該当バージョンのプレビュー・復元ボタン

### SCR-007: 設計図(UML)表示画面

- 表示項目: UML図の描画領域
- 操作ボタン: UML画像ダウンロードボタン

## 2.4 外部システム・API連携仕様

| サービス | 用途 | 認証 | タイミング | 要件 |
|---|---|---|---|---|
| 外部AIサービス | チャットヒアリングの対話生成、4種の設計書一括生成、自己診断の実行 | APIキー | ユーザーのリクエスト時 | FR-001・FR-002・FR-003 |

## 2.5 データ入出力仕様

- 入力データ: 参考資料ファイル(txt, md, pdf、最大3件)、チャットメッセージ(数千文字まで)
- 出力データ: Markdown形式の設計書ファイル(ダウンロード用)、自己診断結果データ
- バリデーション: 空送信の禁止、ファイル形式およびサイズ制限の検証

## 2.6 API一覧

| メソッド | パス | 概要 | 関連画面 | 要件 | 本文 | 応答 | エラー |
|---|---|---|---|---|---|---|---|
| POST | /api/v1/auth/login | ログイン認証 | SCR-001 | FR-006 | email, password | 200 認証成功とJWTトークン | 401 認証失敗 |
| POST | /api/v1/projects | プロジェクト作成と参考資料読み込み | SCR-002 | FR-005・NFR-007 | title, files | 201 プロジェクト作成成功 | 400 不正なリクエスト、401 認証エラー |
| POST | /api/v1/projects/{id}/chats | チャットメッセージ送信と応答取得 | SCR-003 | FR-001・FR-007・FR-008 | message | 201 メッセージ送信成功とAI応答 | 400 空送信・文字数超過、500 AI応答失敗 |
| POST | /api/v1/projects/{id}/generate | 設計書一括生成と自己診断の実行 | SCR-004 | FR-002・FR-003 | options | 201 設計書生成成功 | 500 生成処理失敗 |
