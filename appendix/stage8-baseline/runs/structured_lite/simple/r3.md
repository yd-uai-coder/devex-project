1. **[最重要 / 設計]** POST /api/v1/auth/login, 2.3 主要画面のUI/UX仕様 SCR-001
   - 問題: JWTアクセストークンおよびリフレッシュトークンの保存先に関する仕様が文書内で矛盾しています。
   - 理由: 要件定義書のFR-002では「HttpOnly Cookieに保存する」と規定されている一方、外部設計書の2.6 API一覧(POST /api/v1/auth/login)の応答説明では「localStorage に保存する」と記述されています。
   - 改善案: 外部設計書の API 一覧におけるトークンの保存先を「HttpOnly Cookieに保存する」に統一して修正してください。
2. **[中程度 / 設計]** テーブル users, 3.3 バックエンド処理・モジュール設計 DF-2
   - 問題: ユーザーテーブルのパスワードカラムの設計がセキュリティ要件や認証処理と矛盾しています。
   - 理由: 内部設計書の3.2「テーブル: users」の説明において「パスワード(ログイン時にそのまま照合する)」と記載されていますが、一般的なハッシュ化による安全な認証や core/security.py でのハッシュ化方針と矛盾します。
   - 改善案: テーブル users の説明文を「パスワード(ハッシュ化して保存する)」などに修正してください。
