- **[最重要 / 不整合]** 要件定義書 FR-010 / 外部設計書 / 実装計画書
  - 問題: ログインしていない人も閲覧できる共有リンク公開機能（FR-010）が要件定義書に定義されているが、画面一覧、API一覧、および実装計画書のタスクに全く含まれておらず実装できない状態になっている。
  - 理由: 要件定義書のMust要件に対して、外部設計書の画面・APIおよび実装計画書のWBSが連動していないため。
  - 改善案: 共有リンクによる閲覧用の画面・API（例: `GET /api/v1/projects/{id}/public`）を外部設計書に追加し、実装計画書にそれらを構築するタスクを追加する。

- **[最重要 / 設計]** 外部設計書 2.6 API一覧（`POST /api/v1/auth/login`）
  - 問題: 外部設計書の API 一覧表の説明文では「アクセストークン・リフレッシュトークンを応答の本文で返し、フロントエンドは localStorage に保存する」と記載されているが、要件定義書（FR-002）およびヒアリング結果では「リフレッシュトークンは HttpOnly Cookieに保存する」とされている。
  - 理由: 文書間でトークンの保存方針（localStorage と HttpOnly Cookie）に矛盾があるため。
  - 改善案: セキュリティ要件（FR-002）に合わせ、アクセストークンおよびリフレッシュトークンの両方、または少なくともリフレッシュトークンを HttpOnly Cookie で返却・保存する仕様に外部設計書を修正する。
