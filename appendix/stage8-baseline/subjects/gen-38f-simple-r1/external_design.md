# 2. 外部設計書

## 2.1 システム構成概要

### システム構成概要

本システムは、ブラウザからアクセスするフロントエンド(Next.js / Tamagui)、APIおよびAI対話・文書生成ロジックを提供するバックエンド(FastAPI / LangChain / LangGraph)、データ永続化層(PostgreSQL)、およびセッション・レート制限管理(Redis)で構成されます。外部サービスとしてGoogle Gemini API(Gemini Flash-Lite)と連携し、ヒアリングおよび4種のMarkdown設計書の一括生成を行います。VPS環境上にnginxおよびDocker Composeを用いて配置されます。

```text
+-------------------------------------------------------------------------+
|                           Web Browser (PC/SP)                           |
+------------------------------------+------------------------------------+
                                     | HTTPS
+------------------------------------v------------------------------------+
|                            VPS (Reverse Proxy)                          |
|                                   nginx                                 |
+-----------------+------------------------------------+------------------+
                  |                                    |
                  v                                    v
+------------------------------------+   +--------------------------------+
|      Frontend Container            |   |       Backend Container        |
|     Next.js (App Router)           |   |            FastAPI             |
|           Tamagui                  |   |    (LangChain / LangGraph)     |
+------------------------------------+   +---+--------------+----------+--+
                                             |              |          | API
                         +-------------------+              |          v
                         v                                  v     +-------+
                 +--------------+                   +-------------+|Gemini |
                 |  PostgreSQL  |                   |    Redis    ||Flash- |
                 | (Chat / Docs)|                   |(Rate Limit) ||Lite  |
                 +--------------+                   +-------------++-------+
```

## 2.3 主要画面のUI/UX仕様

### SCR-001: ログイン・新規登録画面

- 入力項目:
  - メールアドレス入力欄
  - パスワード入力欄
- 表示項目:
  - タブ切替（ログイン / 新規登録）
  - エラーメッセージ表示エリア（入力不備、認証失敗、レート制限警告等）
- 操作ボタン・アクション:
  - 「ログイン」または「登録する」ボタン（押下で認証API実行、JWT発行・Cookie保存後、SCR-002へ遷移）

### SCR-002: プロジェクト一覧画面

- 表示項目:
  - プロジェクト一覧カード（プロジェクト名、最終更新日時、ステータス: ヒアリング中/設計書生成済）
  - ユーザー情報およびログアウトボタン
- 操作ボタン・アクション:
  - 「新規プロジェクト作成」ボタン（押下でSCR-003へ遷移）
  - 各プロジェクトカード選択（押下で該当プロジェクトのSCR-004へ遷移）
  - 「ログアウト」ボタン（押下でトークン失効後、SCR-001へ遷移）

### SCR-003: プロジェクト作成・資料設定画面

- 入力項目:
  - プロジェクト名入力欄（必須）
  - 参考資料ファイルアップローダー（txt, md, pdf形式、最大3件まで）
- 表示項目:
  - 添付済みファイル一覧（ファイル名、ファイルサイズ、削除アイコン）
  - バリデーションエラーメッセージ（拡張子不正、容量超過、4件以上登録時の警告）
- 操作ボタン・アクション:
  - 「ヒアリングを開始する」ボタン（プロジェクトを初期化し、SCR-004へ遷移）
  - 「キャンセル」ボタン（SCR-002へ遷移）

### SCR-004: ヒアリング対話チャット画面

- 表示項目:
  - プロジェクト名ヘッダー
  - チャットタイムライン（ユーザー発言、AI発言、送信時刻）
  - AI生成中ローディングインジケーター（初速待機表示、生成中状態）
  - 生成失敗時のエラー通知（理由表示および再送プロンプト）
- 入力項目:
  - メッセージ入力テキストエリア（空送信抑止、最大文字数カウンター表示）
- 操作ボタン・アクション:
  - 「送信」ボタン（押下でメッセージ送信、AI応答受信。生成中は無効化）
  - 「4種設計書を一括生成する」ボタン（ヒアリング完了後押下可能。生成開始確認ダイアログ表示）
  - 「設計書プレビューへ」ボタン（生成完了時に活性化、SCR-005へ遷移）

### SCR-005: 設計書プレビュー・診断画面

- 表示項目:
  - 設計書切替タブ（「要件定義書」「外部設計書」「内部設計書」「実装計画書」）
  - AI自己診断パネル（各文書ごとの「最重要」「中程度」「軽微」の3段階不足点・改善提案）
  - Markdownレンダリングプレビュー表示領域
  - Markdown生テキスト表示切替トグル
- 操作ボタン・アクション:
  - 「クリップボードへコピー」ボタン（現在選択中の設計書Markdownをコピー）
  - 「Markdownファイルをダウンロード」ボタン（.md形式で端末へ保存）
  - 「再生成する」ボタン（生成失敗時または再試行時に再生成APIを呼出）
  - 「チャットへ戻る」ボタン（SCR-004へ遷移）

## 2.5 データ入出力仕様

### データ入出力仕様

#### 1. 入力仕様（参考資料ファイル）
- **対応ファイル形式**: `.txt`, `.md`, `.pdf`
- **ファイル数上限**: 1プロジェクトあたり最大3件
- **受付バリデーション**: ファイル拡張子チェック、MIMEタイプ確認、破損PDFの読込エラー検知。上限超過時は登録を拒否しエラーメッセージを返却。

#### 2. 入力仕様（チャットメッセージ）
- **受付文字数**: 1〜4,000文字
- **バリデーション**: 空文字またはホワイトスペースのみの送信を禁止。4,000文字超過時は送信不可。

#### 3. 出力仕様（設計書エクスポート）
- **形式**: UTF-8形式のMarkdownテキストファイル（`.md`）
- **出力対象**: 要件定義書 (`requirements.md`)、外部設計書 (`external_design.md`)、内部設計書 (`internal_design.md`)、実装計画書 (`implementation_plan.md`)
