# 2. 外部設計書

## 2.1 システム構成概要

```
[ユーザー (Chrome/Edge/Firefox/Safari)]
        │ (HTTPS)
        ▼
[nginx (Reverse Proxy)]
        │
        ├─► Next.js (App Router + Tamagui) [Frontend]
        │         │
        │         ▼ (REST API / JWT)
        └─► FastAPI (Python 3.13 + LangChain/LangGraph) [Backend]
                  │
                  ├─► PostgreSQL [Database (設計書・ユーザーデータ)]
                  ├─► Redis [Cache / Rate Limit / Token Revocation]
                  └─► Gemini Flash-Lite [External LLM API]
```

## 2.2 画面一覧・画面遷移フロー（概要）

| 画面ID | 画面名 | 主要な役割 | 優先度 | 要件 |
|---|---|---|---|---|
| SCR-001 | ユーザー登録画面 | 新規ユーザーがアカウントを作成する画面 | Must | FR-001 |
| SCR-002 | ログイン画面 | 既存ユーザーがメールアドレスとパスワードで認証を行う画面 | Must | FR-002 |
| SCR-003 | チャットヒアリング画面 | AIとのチャットを通じてヒアリングを実施し、参考資料をアップロードする画面 | Must | FR-003・FR-006・FR-007 |
| SCR-004 | 設計書プレビュー・自己診断画面 | 一括生成された4種設計書の確認、自己診断結果の確認、コピー・ダウンロードを行う画面 | Must | FR-004・FR-005 |

```text
SCR-002 (ログイン) ──(成功)──► SCR-003 (チャットヒアリング) ──(生成完了)──► SCR-004 (設計書プレビュー)
SCR-001 (ユーザー登録) ──(成功)──► SCR-002 (ログイン)
```

## 2.3 主要画面のUI/UX仕様

### SCR-001: ユーザー登録画面

- 入力項目: メールアドレス、パスワード
- 操作ボタン: 登録ボタン、ログイン画面へのリンク
- アクション: 入力内容を検証し、登録APIを呼び出して成功時はログイン画面へ遷移する

### SCR-002: ログイン画面

- 入力項目: メールアドレス、パスワード
- 操作ボタン: ログインボタン、ユーザー登録画面へのリンク
- アクション: 認証APIを呼び出し、JWTを取得してチャット画面へ遷移する

### SCR-003: チャットヒアリング画面

- 入力項目: チャットメッセージ入力欄（数千文字まで・空送信禁止）、参考資料アップロード（txt/md/pdf、最大3件）
- 表示項目: チャット履歴一覧、AIからの応答メッセージ
- 操作ボタン: 送信ボタン、資料添付ボタン、設計書一括生成トリガーボタン
- アクション: メッセージ送信時にエラー発生時はメッセージを保存せずに再送を促す、生成ボタン押下で生成処理へ移行する

### SCR-004: 設計書プレビュー・自己診断画面

- 表示項目: 4種設計書（要件定義・外部設計・内部設計・実装計画）のMarkdownプレビュー、AIによる自己診断結果（最重要/中程度/軽微の3段階）
- 操作ボタン: コピーボタン、ダウンロードボタン、チャット画面へ戻るボタン
- アクション: プレビュー画面からクリップボードへのコピーやMarkdownファイルのダウンロードを実行する

## 2.4 外部システム・API連携仕様

| サービス | 用途 | 認証 | タイミング | 要件 |
|---|---|---|---|---|
| Gemini Flash-Lite | チャットヒアリングの対話応答および4種設計書の自動生成、自己診断の実行 | API Key | ユーザーからのチャット送信時および設計書生成リクエスト時 | FR-003・FR-004・CON-004 |

## 2.5 データ入出力仕様

- 受付フォーマット: テキスト入力、参考資料として txt / md / pdf ファイル（最大3件、数千文字以内）
- 出力フォーマット: Markdown形式の設計書ファイル（ダウンロード用）
- バリデーション: 空送信の禁止、ファイル形式・サイズ制限、レート制限（Redisによる不正利用防止）

## 2.6 API一覧

| メソッド | パス | 概要 | 関連画面 | 要件 | 本文 | 応答 | エラー |
|---|---|---|---|---|---|---|---|
| POST | /api/v1/auth/register | ユーザー登録 | SCR-001 | FR-001・NFR-009 | email, password | 201 ユーザー作成成功 | 400 入力値不正, 409 重複登録 |
| POST | /api/v1/auth/login | ログイン | SCR-002 | FR-002・NFR-009 | email, password | 200 ログイン成功 (HttpOnly CookieにJWT設定) | 401 認証失敗 |
| POST | /api/v1/chat/messages | チャットメッセージ送信・ヒアリング | SCR-003 | FR-003・FR-006・FR-007・NFR-003・NFR-009 | message, files (optional) | 200 AI応答メッセージ | 400 空送信・文字数超過, 429 レート制限超過, 500 AI応答失敗 |
| POST | /api/v1/documents/generate | 4種設計書の一括生成と自己診断 | SCR-003 / SCR-004 | FR-003・FR-004・NFR-003 | project_id | 201 生成完了および診断結果 | 400 対象データなし, 429 レート制限超過, 500 生成失敗 |
| GET | /api/v1/documents/{id} | 生成された設計書および自己診断結果の取得 | SCR-004 | FR-004・FR-005・NFR-007 | — | 200 設計書データ一覧 | 404 対象なし, 403 権限なし |
