# 1. 要件定義書

出どころ: **ユーザー** = 初期入力・チャットでの回答より / **採用** = ヒアリングで AI の提案を採用 / **推測** = ドキュメント生成時に AI が推測(未確認。利用者の確認を待つ)。

## 1.1 プロジェクトの目的・背景

X API（Freeプラン）とLLMを組み合わせ、日本国内のトレンドランキングTOP20とその背景解説を自動生成・提供する。

## 1.2 ターゲットユーザー・利用シーン

| 利用者 | 使う場面 | 出どころ |
|---|---|---|
| 一般ユーザー | トップページを開いてその時点のトレンドランキングを見る、またはトレンド入りの背景解説を見る | 採用 |
| 外部クライアント | APIを通じてトレンドデータを取得する | **推測** |

## 1.3 システム化の範囲(In Scope / Out of Scope)

- In Scope: 定期バッチ処理によるトレンド取得と背景解説の自動生成
- In Scope: トップページのトレンドランキング表示
- In Scope: 背景解説ページの表示
- In Scope: 外部向けトレンドデータ提供API
- Out of Scope: ユーザー認証機能
- Out of Scope: 高度な検索・過去履歴の閲覧機能

## 1.4 機能要件(MoSCoW 優先度)

# 2. 外部設計書

## 2.1 システム構成概要

本システムは、X APIとLLMを組み合わせて日本国内のトレンドランキングTOP20とその背景解説を自動生成・提供するWebアプリケーションである。

```
+-------------------------------------------------------------+
|                      一般ユーザー                           |
+-------------------------------------------------------------+
       |                                       ^
       | (HTTP / HTML)                         | (Jinja2)
       v                                       |
+-------------------------------------------------------------+
|                   FastAPI Webアプリケーション                |
|  - トップページ (SCR-001)                                    |
|  - 背景解説ページ (SCR-002)                                  |
|  - APScheduler (定期バッチ)                                 |
+-------------------------------------------------------------+
       |                                       ^
       v (SQL)                                 |
+-------------------------------------------------------------+
|                     PostgreSQL データベース                 |
+-------------------------------------------------------------+
       |                                       ^
       v (API)                                 |
+-------------------+               +-------------------------+
|      X API        |               |         LLM API         |
+-------------------+               +-------------------------+
```

## 2.2 画面一覧・画面遷移フロー（概要）

| 画面ID | 画面名 | 主要な役割 | 優先度 | 要件 |
|---|---|---|---|---|
| SCR-001 | トップページ | 保持している最新のトレンドランキングTOP20を一覧表示する | Must | FR-003 |
| SCR-002 | 背景解説ページ | 選択されたトレンドのLLMによる背景解説を表示する | Must | FR-004 |

```text
SCR-001 (トップページ) --[各トレンド項目のリンク]--> SCR-002 (背景解説ページ)
SCR-002 (背景解説ページ) --[戻るリンク]--> SCR-001 (トップページ)
```

## 2.3 主要画面のUI/UX仕様

### SCR-001: トップページ

- 最新トレンドランキングTOP20のリスト表示項目(順位、前回からの順位変動を示す矢印、トレンド名、取得日時)
- 各トレンド項目から対応する背景解説ページへのリンクボタン
- アクション: ページアクセス時に最新のトレンド情報をJinja2テンプレートでレンダリングして表示する

### SCR-002: 背景解説ページ

- トレンド名およびランクの表示項目
- LLMによって自動生成された背景解説文の表示項目
- トップページに戻るためのナビゲーションリンク
- アクション: 指定されたトレンドIDに対応する背景解説データを取得しJinja2テンプレートで表示する

## 2.4 外部システム・API連携仕様

| サービス | 用途 | 認証 | タイミング | 要件 |
|---|---|---|---|---|
| X API | 日本国内のトレンドランキングTOP10の取得 | OAuth / Bearerトークン | 12時間ごとの定期バッチ実行時 | FR-001・CON-005 |
| LLM API | トレンドに対する背景解説文の自動生成 | APIキー | トレンド取得バッチ内での処理時 | FR-002・CON-006 |
