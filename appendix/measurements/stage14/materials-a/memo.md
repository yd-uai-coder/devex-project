# 運用メモ(発注側の情報システム部門より、2026-11-06)

## 利用する LLM

- 社内の規定により、外部の LLM は **Anthropic の Claude** に限る。背景解説の自動生成も Claude で行うこと。

## 解説が作れなかったとき

- LLM の呼び出しが失敗して背景解説が作れなかったトレンドは、ランキングには出したうえで、
  背景解説ページに **「解説を準備中です」と表示** してほしい(空のページにしない)。

## 過去の分の閲覧

- 企画チームから、**過去7日分のランキングを日付を選んで見られるようにしたい** という要望が来ている。
  情報システム部門としても保存の容量は問題ない。

## そのほか

- 利用者のログイン(認証)は今回も不要。トップページ・背景解説ページは誰でも見られてよい。
