## 数え方

LLM の出力の1項目を、次のどれか1つに分ける(Claude が読んで判定する)。

- **当たり**: 正解の G のどれかと、内容が同じ。対象の ID が正解の対象(括弧の中を含む)のどれかと合っていれば「対象も当たり」、違えば「対象の誤り」として別に数える。1つの G に何項目も当たったら、2つ目からは「重複」。
- **誤り**: どの G にも当たらない。N を違いとした(言い換えの誤検出)、資料に無いことを言う(根拠の無い指摘)、合意済みの内容どうしの食い違い(資料と関係ない)を挙げた、など。誤りの内訳も書く。

指標:
- **拾い漏れ** = 8 −(当たった G の数)
- **誤り** = 誤りの項目の数(内訳: 言い換え / 根拠なし / 資料と無関係)
- **対象の誤り** = 当たったが対象の ID が違う数
- **根拠の引用** = 当たりのうち、資料の文を引用していた数

外部設計書 2.4・2.6 には CR-6 の後も「TOP10」が残っている(合意済みの内容の中の食い違い)。資料はこれに触れていないので、これを挙げた項目は「資料と無関係」の誤りとして数える。
