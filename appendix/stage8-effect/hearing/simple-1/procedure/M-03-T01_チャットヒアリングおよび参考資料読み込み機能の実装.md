# M-03-T01 チャットヒアリングおよび参考資料読み込み機能の実装

> 種別: 機能 / マイルストーン: M-03 M-03: チャットヒアリングと参考資料読み込み機能の実装 / 要件: FR-005, FR-007, FR-008, FR-006 / 依存: M-02-T01

## 目的

チャットセッションの作成・取得、メッセージ履歴の取得、およびファイル添付を伴うメッセージ送信とLLM連携機能を提供する。

## 対象の処理・参照する設計

- 内部設計書 DF-6 POST /api/v1/chat/sessions
- 内部設計書 DF-7 GET /api/v1/chat/sessions
- 内部設計書 DF-8 GET /api/v1/chat/sessions/{id}/messages
- 内部設計書 DF-2 POST /api/v1/chat/messages
- 内部設計書 3.3 `backend/app/api/v1/chat.py`
- 内部設計書 3.3 `backend/app/services/chat_service.py`
- 内部設計書 3.3 `backend/app/services/ai_service.py`
- 内部設計書 3.3 `backend/app/repositories/chat_repo.py`

## 作成・変更するファイル(依存順)

| ファイル | 種類 | 責務 | 根拠 |
|---|---|---|---|
| `backend/app/repositories/chat_repo.py` | モジュール | チャットセッションおよびメッセージデータのPostgreSQLに対するCRUD操作をカプセル化する。 | 内部設計書 3.3 |
| `backend/app/services/ai_service.py` | モジュール | LangChain/LangGraphを介してGemini Flash-Liteを呼び出し、対話応答を生成する。 | 内部設計書 3.3 |
| `backend/app/services/chat_service.py` | モジュール | バリデーション、参考資料の制限・抽出制御、セッションとメッセージの保存を制御する。 | 内部設計書 3.3 |
| `backend/app/api/v1/chat.py` | モジュール | チャット関連のエンドポイントを提供し、認証・認可とリクエスト受け付けを行う。 | 内部設計書 3.3 |
| `backend/tests/api/v1/test_chat.py` | テスト | チャット関連APIの正常系・異常系・バリデーションのテストを行う。 | 実装計画書 4.3 |

## 実装の要点(設計に書いていないことだけ)

- リポジトリ層でSQLAlchemyを用いてchat_sessionsおよびmessagesテーブルの操作を実装する。
- ai_serviceでLangChainとGemini Flash-Liteの統合処理を実装する。
- chat_serviceで文字数制限や参考資料の最大3件制限などの検証ロジックを挟む。
- api/v1/chat.pyのルーターで各サービスを呼び出すように上から順に組み立てる。

| TC-04 | メッセージ送信とAI応答が正しく処理されること | POST /api/v1/chat/messages | 結合テスト(FastAPI TestClient) | app/services/ai_service.py(モック化されたLLM応答を返す) |
