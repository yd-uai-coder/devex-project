# M-03-T03 生成文書および自己診断結果の取得機能の実装

> 種別: 機能 / マイルストーン: M-03 M-03: 設計書一括生成と自己診断機能 / 要件: FR-003, FR-005, FR-006, FR-009 / 依存: M-03-T02

## 目的

指定されたプロジェクトに紐づく確定した4種のMarkdown設計書および自己診断結果を取得するAPI機能を実装する。

## 対象の処理・参照する設計

- 段階5 F-11 生成文書および自己診断結果を取得する
- 段階6 get_documents(`app/api/routes/projects.py`)(設計に無い ── 未定義を参照)
- 段階6 get_project_documents(`app/services/project.py`)(設計に無い ── 未定義を参照)
- 段階6 find_by_id(`app/repositories/project.py`)(設計に無い ── 未定義を参照)
- 段階6 get_documents_and_diagnosis(`app/repositories/project.py`)(設計に無い ── 未定義を参照)
- 段階4 `app/api/routes/projects.py`
- 段階4 `app/services/project.py`
- 段階4 `app/repositories/project.py`

### シーケンス図(段階5 F-11 生成文書および自己診断結果を取得する の手順から導出)

```mermaid
sequenceDiagram
  participant P1 as 利用者
  participant P2 as app/api/routes/projects.py
  participant P3 as app/services/project.py
  participant P4 as app/repositories/project.py
  P1->>P2: 1: get_documents(指定プロジェクトID)
  Note over P1,P2: 1a 認証トークンが無効または期限切れ → UnauthorizedError → 401
  P2->>P3: 2: get_project_documents(指定プロジェクトID、ユーザーID)
  Note over P2,P3: 2a プロジェクトに対する権限がない → ForbiddenError → 403
  Note over P2,P3: 2b プロジェクトが存在しない → NotFoundError → 404
  P3->>P4: 3: find_by_id(指定プロジェクトID)
  P4-->>P3: (3 の戻り) プロジェクト情報
  P3->>P4: 4: get_documents_and_diagnosis(指定プロジェクトID)
  P4-->>P3: (4 の戻り) 4種のMarkdown設計書、自己診断結果
  P3-->>P2: 5: 4種のMarkdown設計書、自己診断結果
  P2-->>P1: 6: 設計書および自己診断結果のレスポンス
```
