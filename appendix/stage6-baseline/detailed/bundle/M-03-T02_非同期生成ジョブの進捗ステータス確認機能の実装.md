# M-03-T02 非同期生成ジョブの進捗ステータス確認機能の実装

> 種別: 機能 / マイルストーン: M-03 非同期設計書生成とジョブ管理機能の実装 / 依存: M-03-T01

## 目的

非同期生成ジョブの進捗ステータス確認機能(F-10)を実装し、指定したジョブの進捗状態を取得して返却できるようにする。

## 対象の処理・参照する設計

- 段階5 F-10 非同期生成ジョブの進捗ステータス確認
- 段階6 JobService.get_job_status(`app/services/job.py`)(設計に無い ── 未定義を参照)
- 段階6 SummaryRepository.find_by_job_id(`app/repositories/summary.py`)(設計に無い ── 未定義を参照)
- 段階4 `app/api/documents.py`
- 段階4 `app/services/job.py`
- 段階4 `app/repositories/summary.py`

### シーケンス図(段階5 F-10 非同期生成ジョブの進捗ステータス確認 の手順から導出)

```mermaid
sequenceDiagram
  participant P1 as 利用者
  participant P2 as app/api/documents.py
  participant P3 as app/services/job.py
  participant P4 as app/repositories/summary.py
  P1->>P2: 1: プロジェクトID, ジョブID
  Note over P1,P2: 1a リクエストの検証に失敗した場合 → ValidationError → 400
  P2->>P3: 2: JobService.get_job_status(プロジェクトID, ジョブID)
  Note over P2,P3: 2a 対象のジョブが存在しない場合 → NotFoundError → 404
  P3->>P4: 3: SummaryRepository.find_by_job_id(ジョブID)
  P4-->>P3: (3 の戻り) ジョブ情報
  P3-->>P2: 4: 進捗ステータス
  P2-->>P1: 5: 進捗ステータス
```
